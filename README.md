# In silico-Based Novel Antigen Identification
**Overall Workflow**

Reference proteome
    
1. Proteome retrieval & quality control
     
2. Remove redundant proteins
  
3. Subtractive proteomics
   
       . Remove host-homologous proteins
       . Remove highly conserved/non-specific proteins
       . Retain pathogen/tick-specific proteins
    
4. Essentiality analysis
   
5. Subcellular localization
     
6. Antigenicity prediction
      
7. Allergenicity / toxicity screening
      
8. Physicochemical characterization
       
9. Conservancy / strain analysis
     
10. Functional & domain annotation
       
11. Structural characterization
      
12. Final candidate ranking
